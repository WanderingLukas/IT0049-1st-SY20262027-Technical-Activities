# TFA1 – CodeIgniter POS System

## Project Description
This project is a basic Point-of-Sale (POS) website developed using **CodeIgniter 4** and PHP for the IT0049 – Web System Technologies course.

The purpose of this activity is to demonstrate the fundamentals of web development using CodeIgniter's routing, controllers, views, and MVC architecture. It uses static PHP arrays to display sample customer and user information without requiring a database.

## Features
The website consists of four pages:

- **Home Page (`/`)** – Displays a welcome message and navigation links.
- **About Page (`/about`)** – Provides basic information about the POS system.
- **Customer Accounts (`/customers`)** – Displays customer names, emails, and phone numbers.
- **User Accounts (`/users`)** – Displays staff usernames, full names, and roles.

## Programs used
- PHP
- CodeIgniter 4
- HTML
- Composer
- XAMPP (Apache)
- Visual Studio Code

## How to Run
1. Install XAMPP and Composer.
2. Clone or download the project into your XAMPP `htdocs` directory.
3. Open the project folder in Visual Studio Code.
4. Run `composer install` to install dependencies.
5. Configure the `app.baseURL` in your `.env` file.
6. Start Apache using XAMPP.
7. Open the project in your browser using the configured local URL.
