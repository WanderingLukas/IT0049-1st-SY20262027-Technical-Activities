# Tasks for Today Management System

## Project Description

The Tasks for Today Management System is a simple web-based application developed using **CodeIgniter 4, PHP, and MySQL**. This project was created for IT0049 – Web System Technologies as part of Technical Summative Assessment 1 (TSA1).

The system demonstrates the implementation of the **Model-View-Controller (MVC)** architecture, database integration, routing, and data retrieval.

## Features

- Welcome Page: Displays only tasks scheduled for the current date.
- All Tasks Page:*Displays all recorded tasks, regardless of date, sorted chronologically.
- Profile Page: Retrieves and displays a demo user's information from the database.
- About Page: Provides information about the system and its developer.

## Programs used 

- CodeIgniter 4
- PHP
- MySQL
- HTML
- XAMPP

## Purpose

The purpose of this activity is to demonstrate how CodeIgniter 4 uses MVC architecture to organize a web application and interact with a MySQL database. It focuses on retrieving, filtering, and displaying task records across multiple webpages.
